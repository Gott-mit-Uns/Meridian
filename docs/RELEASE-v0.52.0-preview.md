# Meridian · 首个公开预览版

Meridian 是 Xiaomi EV Mate 的非官方 Android 客户端，采用 Kotlin + Jetpack Compose 构建，支持车辆状态、行程/充电、足迹、AI助手、用车统计、账本与个性化首页。

**必须先部署 [Ponyix/xiaomiev-mate](https://github.com/Ponyix/xiaomiev-mate)，在网页端完成账号与车辆配置，再在App填写自己的HTTPS服务地址和账号。单独安装APK无法读取车辆数据。**

## 本次公开内容

- 五栏导航：爱车、行程、AI助手、统计、我的。
- 玻璃胶囊、明暗主题、多彩主题及“明亮橙彩”。
- 首页卡片拖动、移除与恢复；本月费用和每公里费用卡片。
- 行程与充电详情、轨迹、手记和收藏。
- AI聊天、Markdown、推荐问题、图片与历史会话。
- 用车/能耗/月度/年度报告及主题图片分享。
- 分类账本、充电电价估算、周/月/年账单统计。
- 本机头像、隐私模式、桌面卡片、管理与资料相关功能。
- 0.52修正行程手记编辑，改为在卡片内展开保存与取消。

## 下载

- `Meridian-v0.52-preview.apk`：ARM64，优先供现代Android手机使用。
- `Meridian-v0.52-armeabi-v7a-preview.apk`：32位ARM设备兼容版本。
- `SHA256SUMS.txt`：安装包校验值。

最低Android 8.0。预览包应用ID为 `app.meridian.mobile.preview`，可以覆盖使用同一维护者签名的旧预览版；自行编译的不同签名安装包不能直接覆盖。

## 开发方式与验证

项目全程采用AI辅助开发：Meridian自有功能代码、界面、修复、测试与文档由AI根据需求迭代，作者负责需求、设计选择和真机反馈；第三方依赖和复用组件保留原归属。

公开源码独立构建通过，168项JVM单元测试通过，Lint无错误。预览版仍可能有设备兼容、动效和布局问题；没有完整UI自动化或全面安全审计保证。欢迎提交已脱敏的复现步骤和截图。

源码MIT，第三方SDK、地图、车图及品牌内容遵循各自条款。详细说明和7张真实截图见仓库README。
