# 隐私与数据范围

## 连接

App 连接用户手动填写的 Xiaomi EV Mate 服务实例，使用该实例的账号会话。没有内置可共享的车辆账号或服务Key。

在选择记住登录时，本地使用 Android Keystore 相关加密机制保存登录信息；注销、清理应用或重装的具体影响应以当前界面操作为准。设备系统安全和所连接后端的安全同样重要。

## 本机资料

账单、手记、收藏、头像、布局偏好和部分已读取数据保存在设备。账单与手记按服务、账号及车辆范围区分，不自动上传为后端的账单/手记数据。

备份与恢复请区分后端备份和App本机资料；不能假定单独导出服务端数据库就包含手机本地账单。清理应用数据或卸载前先确认所需资料已导出。

## 外部服务

- AI消息和附件提交给所配置的后端；后端是否进一步调用模型服务由后端配置决定。
- 远程查看使用后端返回的视频会话，客户端实现为接收画面，不发布本机摄像头或麦克风轨道。
- 地图底图和部分区县边界需要访问地图/CDN服务，其使用规则和数据处理由相应提供者决定。
- Android 分享会把生成的图片交给用户选定的目标应用。

## 隐私模式与分享

文字地址隐藏不等于地图脱敏；地图、轨迹形状、时间和城市也可能透露位置。分享前根据需要选择隐藏地址、路线等内容，并查看预览。

公开提 Issue 时不要附带密码、Key、Token、Cookie、真实备份文件、完整私有配置、车架号或精确轨迹。安全问题请通过 GitHub 私密安全报告渠道反馈，不要在公开Issue发布凭据或可利用细节。
